## 7. 阶段 3 · P0 功能修复与融合闭环实现

### 7.1 目标

- 修复 Electron 中文 JSON 与 SSE 跨 chunk 解码乱码。
- 统一附件 Artifact 管线，避免旧新路径分裂。
- 引入结构化 ImageObservation 与主动图片 VisualIntentRouter 边界。
- 补齐前端附件预览、安全动作和专用向量知识库连接尝试。

### 7.2 任务

| 任务 | 内容 | 关联任务 |
|---|---|---|
| UTF-8 解码 | JSON Buffer 合并后统一解码，SSE 使用安全流式解码 | Task 3.1 |
| 附件 Artifact | 定义兼容字段并统一上传、状态、历史、水合和上下文来源 | Task 3.2 |
| ImageObservation | 设计图片观察结构，接入 VLM/OCR provider 边界，默认不进入长期记忆 | Task 3.3 |
| VisualIntentRouter | 定义角色自拍、环境物、文档截图、表情包等主动图片意图 | Task 3.4 |

| 向量知识库 | 探测现有向量能力，成功则索引摘要，失败则记录阻塞证据 | Task 3.6 |
