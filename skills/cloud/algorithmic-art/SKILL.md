# 生成艺术（algorithmic-art）

用代码（首选 p5.js）创作**生成艺术 / 算法艺术**时使用：种子随机、参数可调、可复现。核心不是"随机出好看的东西"，而是**用受控的随机性探索参数空间**，并保证作品原创、可复现、可交互。

## 铁律

1. **一切随机都走种子**：用 `randomSeed()` / `noiseSeed()` 或自己的 PRNG，保证同一 seed 永远得到同一张图；禁止用不可复现的 `Math.random()`。
2. **参数集中可调**：把种子、密度、配色、尺度等抽成顶部一组参数，改一个值就能得到一串变体，方便探索。
3. **原创不临摹**：借鉴数学规律（流场、L-system、Voronoi、反应扩散等）与作品气质，但**不复制**在世艺术家的具体作品或签名风格。
4. **可实时交互**：把关键参数接到交互控件（滑杆/按键），让人能现场调参并看到即时变化。
5. **确定性优先**：除时间、鼠标这类交互输入外，画面必须由 seed 与参数唯一决定，便于保存与复现。

## 步骤

1. **定概念**：一句话说清要探索的视觉结构（如"噪声驱动的粒子流场"），并选出对应的算法机制。
2. **搭脚手架**：p5.js 基础结构（`setup` 设画布与 `randomSeed`，`draw` 或一次性绘制），参数提到顶部。
3. **实现核心算法**：先用最简参数跑通一个能出图的版本，再逐步加细节，绝不在没跑通时叠加复杂度。
4. **接交互**：把 3~5 个关键参数做到界面上，支持实时调整，并提供"随机新种子"按钮。
5. **调色**：配色从主题或有限色板取，避免高饱和堆砌，保证主体与背景对比。
6. **导出与复现**：支持 `saveCanvas` 导出，并在界面上显示当前 seed，方便复现同一结果。
7. **性能与收尾**：控制粒子/图层数量避免掉帧；`prefers-reduced-motion` 时降低动画频率。

## 输出形态

```
## 概念
（一句话视觉结构 + 采用的算法机制）

## 参数
- seed / 密度 / 尺度 / 配色 / 迭代次数 …

## 交互
- 滑杆：…  按键：…  导出：saveCanvas

## 代码
（单文件 p5.js：setup/draw + 参数区，randomSeed 固定）

## 复现
- seed=… → 同一结果
```

## 反面例子（不要这样）

- 用 `Math.random()` 不设种子，每次刷新都不一样、无法复现。
- 参数写死在代码各处，想调密度得翻遍整个文件。
- 直接照搬某位在世艺术家的标志性风格或作品。
- 一上来就堆满复杂逻辑，连一张能看的图都没跑出来。
- 粒子数量失控导致页面掉帧，也没有任何降级方案。
