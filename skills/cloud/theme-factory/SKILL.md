# 主题工厂（theme-factory）

当需要给一份已有产物（网页、报告、幻灯片等）**套用统一主题**，或要求"换个配色/风格"时使用。它做的是把一套设计 token（颜色、字体、圆角、阴影、间距）一致地应用到产物的每个角落，而不是东一块西一块地零散调整。

## 铁律

1. **主题即 token 集**：一套主题必须收敛成几个 CSS 变量，改主题 = 改这几个变量，不动结构代码。
2. **全局一致**：同一语义在整个产物里永远用同一个 token（正文永远是同一档灰，按钮永远是同一主色），绝不出现两个相近但不相同的蓝。
3. **对比度达标**：任何前景/背景组合对比度不低于 4.5:1（大字号不低于 3:1），换肤不能牺牲可读性。
4. **克制用色**：主色用作强调，大面积背景用中性色，强调色一屏最多出现一两处。
5. **深色模式成对设计**：亮色与暗色的值同时给出，不用简单反色糊弄。

## 步骤

1. **盘点产物**：列出所有出现颜色、字体、圆角、阴影的地方，区分硬编码与已是变量的部分。
2. **选或造主题**：优先复用已有预设主题；需要新建时先定气质（专业/活泼/极简），再推导 token。
3. **定义 token**：写成 `:root` 下的 CSS 变量，颜色按语义层命名（`--background/--foreground/--primary/--muted/--border`），不要用 `--blue-500` 这种描述性命名。
4. **替换硬编码**：把产物里的写死值逐个换成 `var(--token)`，确保无遗漏。
5. **补深色模式**：给出 `@media (prefers-color-scheme: dark)` 或 `.dark` 下的对应取值。
6. **校验对比度**：逐对检查前景与背景，标出并修掉不达标的组合。
7. **出预览**：给出一段能直接看到主题效果的片段或说明。

## 输出形态

```
## 主题名与气质
（一句话）

## Token 定义
:root { --background: …; --foreground: …; --primary: …; --muted: …; --border: …; --radius: …; }
.dark { … }

## 应用范围
- 已替换硬编码：… 处
- 涉及组件：按钮 / 卡片 / 标题 …

## 对比度校验
- 正文/背景：…（达标）  次要文字/背景：…（达标）
```

## 反面例子（不要这样）

- 主题里写 `--blue-500: #3b82f6` 这种命名，语义一变全部得改。
- 只改了主色，其余颜色仍散落各处硬编码。
- 换肤后浅灰文字压在浅灰背景上，对比度不达标。
- 只做亮色主题，深色模式靠浏览器反色糊弄。
