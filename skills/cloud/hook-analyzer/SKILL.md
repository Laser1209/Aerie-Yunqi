# 视频前三秒钩子分析（hook-analyzer）

当你要评估一条短视频**开头 3 秒能不能抓住人**时走这份流程。输入通常是该视频的分镜拆解数据（含每段时长、画面描述、字幕或文案、关键帧），产出是对钩子强度的结构化评估与改进建议。

## 铁律

1. **只聚焦 0~3 秒**：把起点到 3.0 秒的分镜单独拎出来，后面的内容一律不纳入钩子分析。
2. **数信息事件，而不是看时长**：判断这 3 秒里发生了几个"信息事件"（画面变化、字幕出现、动作、声音），事件太少的开头留不住人。
3. **钩子要给出"为什么继续看"**：悬念、冲突、反常识、强利益点、身份代入——至少命中一个，否则就是流水账。
4. **文字与画面要互相补足**：字幕说 A、画面演 B 且不相关时，注意力会被撕成两半。
5. **区分"抓眼"与"抓对的人"**：靠标题党博眼球与精准吸引目标受众不是一回事，评估时要点明。
6. **结论必须给可改动作**：指出"第 0.8 秒加一句钩子文案"这类具体调整，而不是"可以更有吸引力"。

## 步骤

1. **摘取前三秒分镜**：筛出时间落在 0~3.0s 的分镜段落，列出每段的起止时间与内容。
2. **数信息事件**：逐段标注画面元素、字幕文案、动作、音效，统计总事件数。
3. **判钩子类型**：判断开场用了悬念、冲突、反差、利益、代入中的哪一种或哪几种。
4. **评估文字与画面一致性**：检查字幕与主画面是否在讲同一件事。
5. **找流失点**：指出最可能让人划走的那一刻（前 1 秒无信息、字幕过长、画面静止等）。
6. **给改进**：针对流失点给出具体动作与位置（在第几秒改什么）。
7. **打分**：按信息密度、钩子类型、文画一致、前 1 秒强度给一个综合判断。

## 输出形态

```
## 前三秒分镜
- 0.0~1.2s：<画面> / 字幕"…"
- 1.2~3.0s：<画面> / 字幕"…"

## 信息事件
- 共 N 个（画面变化 x，字幕 x，动作 x）

## 钩子类型
- 命中：反常识  缺失：利益点

## 流失点
- 0.0~0.8s 画面静止、无字幕 → 高概率划走

## 改进
- 第 0.0s 直接抛出结果画面 + 一句悬念字幕

## 评分
- 信息密度 中 / 钩子强度 弱 / 文画一致 是 → 建议重做开头
```

## 反面例子（不要这样）

- 把整条视频分析一遍，钩子结论只在结尾轻描淡写一句。
- 只说"开头不够吸引人"，不指出第几秒、改什么。
- 只夸钩子"很炸"，不区分它是博眼球还是精准吸人。
- 用整条视频的平均节奏替代前三秒的评估。
