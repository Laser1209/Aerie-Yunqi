# 海报与静态视觉设计（canvas-design）

要产出一张**静态视觉作品**（海报、封面、banner、宣传图）时使用，输出为图片或可打印的 PDF。它关注固定画布上的**构图、层级、留白与冲击力**——一张图只讲一件事。

## 铁律

1. **一张图一个主张**：海报只传达一个核心信息，主标题加一个视觉主体，其余全部删掉。想塞三件事的图一定失败。
2. **先定画幅比例**：开工前确定尺寸与比例（如 4:3 打印、9:16 竖版、16:9 banner），所有元素按这个画幅构图，不留半截。
3. **建立强层级**：主标题的视觉权重必须压倒一切（最大字号或最强对比），副标题、正文、署名依次递减。
4. **留白即呼吸**：主体周围要留出足够边距，一般不小于画幅短边的 5%，元素不要贴边。
5. **配色受控**：一张图不超过 3~4 种颜色，用对比而非数量制造视觉张力。

## 步骤

1. **定用途与画幅**：明确展示场景（打印 / 社媒 / 网页 banner）与精确尺寸、出血区。
2. **写一句话主信息**：把它当作唯一文案核心，其余文字都是它的注脚。
3. **选构图**：确定主体位置与视线动线（居中 / 三分 / 对角），并预留标题区与安全边距。
4. **定配色与字体**：从已有规范或主题取色，字体选一到两款，保证远距离可读。
5. **排文字**：主标题字号最大、字重最重；行距字距适度收紧；避免文字压在图的关键细节上。
6. **出图**：导出 PNG（屏幕）或 PDF（打印）；打印版确保分辨率不低于 300dpi、含出血。
7. **缩略图检验**：把成品缩到拇指大小看一眼，主角信息还认得出才算合格。

## 输出形态

```
## 画幅
（尺寸 / 比例 / 用途 / 出血）

## 主信息
（一句话核心 + 注脚文案）

## 构图
- 主体：…  位置：…  视线动线：…
- 标题区 / 安全边距：…

## 配色与字体
- 色值：#…  字体：…

## 产物
（图片或可打印 PDF 的设计描述 / 生成参数）
```

## 反面例子（不要这样）

- 一张海报上并列五个卖点，结果谁也没记住。
- 文字紧贴边缘，打印时被裁掉一半。
- 用七八种颜色制造"丰富感"，画面嘈杂。
- 缩到缩略图大小后，主标题已经看不清。
- 打印稿直接用屏幕 RGB 输出，色彩失真。
