# HyperFrames 媒体预处理（hyperframes-media）

当你要为视频合成准备素材——文本转语音、把语音转成带时间戳的字幕、把主体从背景里抠出来——时走这份流程。产出是可直接被 composition 使用的音频、字幕与透明素材。

## 铁律

1. **配音先定文本与音色**：TTS 只吃干净文本，标点、换行、数字读法都会影响断句，文本不过关重跑多少次都一样。
2. **字幕必须来自真实语音时间**：用转写工具（Whisper）拿到带时间戳的片段，不要凭句子长度估算时间。
3. **转写后要校对**：专有名词、同音字、数字极易错，逐条比对修正后再用于字幕。
4. **抠图输出透明通道**：需要叠加到画面上的主体要输出带 alpha 的素材（PNG 或 ProRes），不要抠完还带背景色。
5. **素材命名带语义**：`scene3-narration.wav`、`scene3-caption.srt`、`logo-cutout.png`，比 `out1/out2` 好维护得多。
6. **一次生成、多处复用**：同一段语音的音频与字幕配对保存，后续改画面时无需重生成。

## 步骤

1. **确认用途**：这份素材给哪一段（场景或时间点）用，需要什么形态（音频 / 字幕 / 透明图）。
2. **处理文本**：把要朗读的文本整理干净，确认数字、术语、断句。
3. **生成配音**：选音色执行合成，输出音频文件并记录时长。
4. **转写字幕**：对音频做语音转写，得到带时间戳的文本片段。
5. **校对字幕**：逐条核对文本正确性与时间点，修正错字与错位。
6. **抠图（如需）**：对含主体的图片或视频做背景移除，输出透明通道素材并检查边缘是否干净。
7. **整理交付**：按语义命名，配对保存音频与字幕，登记时长与用途。

## 输出形态

```
## 素材清单
| 用途 | 文件 | 类型 | 时长/尺寸 |
| 场景3旁白 | scene3-narration.wav | audio | 12.4s |
| 场景3字幕 | scene3-caption.srt | subtitle | 24 条 |
| LOGO | logo-cutout.png | image(alpha) | 512x512 |

## 校验
- 字幕条数与音频时长匹配：是
- 抠图透明边缘干净：是
```

## 反面例子（不要这样）

- 用整段带着奇怪标点的文本直接合成，断句全乱还反复重试。
- 字幕靠均分句子时长，结果与语音全程错位。
- 转写完不校对，专有名词全错。
- 抠图输出白底 JPG，叠到画面上带着一块背景。
