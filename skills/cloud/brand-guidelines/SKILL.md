# 品牌视觉规范（brand-guidelines）

当产物需要体现某个品牌（默认 Anthropic 风格，也可指项目自有品牌）的官方视觉时使用。它约束的是**颜色、字体、留白、语气**的一致性——让任意两个出自本品牌的产物放在一起，看不出是不同人做的。

## 铁律

1. **颜色只用品牌色板**：主色、辅助色、中性色都取自品牌规范，禁止"我觉得这个蓝更好看"式的自由发挥。
2. **字体按层级固定搭配**：品牌标题字体与正文字体是配对的，标题用一款、正文用一款，靠字重字号拉开层次，不混第三款。
3. **留白体现品牌调性**：品牌若偏优雅克制，留白就要充足，不要塞满；调性靠间距与节奏传达，而非靠元素数量。
4. **文案语气一致**：用词、人称、标点风格遵循品牌语气指南（正式/亲切/技术），不中英混排，不忽冷忽热。
5. **标志有安全区**：logo 周围留出规定的最小间距，不得拉伸、改色、加描边或加投影。

## 步骤

1. **确认品牌与来源**：明确用哪个品牌规范，取到官方色值（十六进制/RGB）、字体名与语气示例。
2. **建 token**：把品牌色写成 CSS 变量或设计 token，字体声明 `font-family` 并给出回退字体链。
3. **应用到产物**：所有颜色与字体都引用 token，禁止散落硬编码。
4. **核对标志用法**：logo 的尺寸、安全区、最小可用尺寸、深浅背景版本是否正确。
5. **校准语气**：逐句检查文案是否符合品牌语气，统一人称与标点。
6. **交叉验证**：把产物与另一个已知合规的品牌产物并排看，风格是否协调。
7. **输出规范说明**：列出所用色值、字体与关键间距，便于后续复用。

## 输出形态

```
## 品牌与来源
（品牌名 + 规范出处）

## 视觉 token
- 主色：#…  辅助色：#…  中性色：#… / #… / #…
- 标题字体：…  正文字体：…（含回退链）
- 关键间距 / 圆角 / 阴影

## 应用结果
（产物代码或设计说明，全部引用 token）

## 合规核对
- 标志安全区：OK  色彩：仅用品牌色  语气：一致
```

## 反面例子（不要这样）

- 随手挑了个"更亮"的蓝色替换品牌主色。
- 标题混用两三款字体，风格打架。
- 把 logo 拉变形、加投影，或放在低对比背景上看不清。
- 文案语气前后不一致，一会儿正式一会儿卖萌。
