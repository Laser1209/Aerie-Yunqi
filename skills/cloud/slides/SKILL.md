# PowerPoint 幻灯片（slides）

当用户需要一份**可编辑的 .pptx 演示文稿**（不是网页版）时使用。
用 PptxGenJS 之类的库生成文件，含标题页、目录、内容页、原生图表与结束页。

## 铁律

1. **一页一个论点**：标题写论点，正文最多 6 条要点或一张图；溢出就拆页。
2. **版式统一**：全篇同一套模板——字体、字号、主色、页边距、标题位置固定，不要每页各写各的。
3. **字体要落地**：选目标机器上大概率存在的字体（如 微软雅黑 / Arial），避免打开时被静默替换导致换行错位。
4. **不溢出、不重叠**：文本框尺寸按最大字数预留；生成后必须逐页检查文字是否超出框、元素是否压线。
5. **图表用原生组件**：数据用 pptx 原生图表，不要贴 Excel 截图，方便对方改数。
6. **可编辑**：文字放进文本框而不是图片，对方能直接改。

## 步骤

1. **定大纲**：每页写 标题（论点）+ 要点或图形说明，先确认大纲再生成。
2. **定模板**：确定母版规格——页面尺寸（16:9）、字体与字号（标题 28~32pt，正文 16~20pt）、主色、统一页边距。
3. **生成文件**：用 PptxGenJS 逐页生成；标题页、目录页、内容页、图表页、结束页结构固定。
4. **摆图表**：数据页用原生 chart，设定轴单位与图例。
5. **逐页自检**：导出后逐页看——文字溢出框、元素重叠、字体被替换、标点出现在行首、图片变形；发现问题回到参数修正。
6. **兼容确认**：在目标环境（Windows Office / WPS / Keynote）打开确认版式不跑偏。
7. **交付**：给出文件路径，并说明哪些是原生文本与图表（可直接编辑）。

## 输出形态

```
deck.pptx
├─ P1 标题页：主题 / 汇报人 / 日期
├─ P2 目录：3~5 节
├─ P3..N 内容页：标题(论点) + 要点 ≤6 条 或 一张原生图表
├─ P(N+1) 数据页：原生 chart（轴单位 + 图例）
└─ P(N+2) 结束页：结论 / 下一步 / 联系
规格：16:9，标题 28~32pt，正文 16~20pt，统一页边距与主色
```

## 反面例子（不要这样）

- 一页 12 条要点，字号缩到 12pt，投影上看不清。
- 用了系统没有的字体，别人打开后排版全乱。
- 图表直接贴 Excel 截图，对方改不了数据。
- 每页版式自由发挥，整体像拼贴。
