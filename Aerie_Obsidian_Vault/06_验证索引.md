## 验证类型

| 类型 | 说明 |
| --- | --- |
| 单元测试 | 验证函数、类、模块局部行为 |
| 集成测试 | 验证多个模块协作与接口契约 |
| E2E 测试 | 验证用户路径与端到端业务闭环 |
| 手工验证 | 验证 UI、流程、环境或无法自动化部分 |
| 文档验证 | 验证知识库、报告、索引与证据完整性 |
