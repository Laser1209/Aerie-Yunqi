# HTML PPT 单页（ppt-page）

当用户要把大纲、文章、截图、图片或已有 deck 变成**单文件 HTML 幻灯片**时使用。
形态是垂直单列、限宽卡片式的滚动 PPT：卡片下方配注释，可按页全屏演示，双击即开、离线可用。

## 铁律

1. **一页一个论点**：每张卡片只讲一件事，论点放标题，论据放卡片内。
2. **单文件离线**：图片转 base64 或内联，不引用 CDN；断网也能正常演示。
3. **卡片限宽**：正文卡片最大宽度约 880~960px 居中；不要拉满全屏，否则大屏上阅读困难。
4. **卡片下方配注释**：每张卡片下方给 caption（讲稿/说明），页面上提供全局开关。
5. **不溢出**：标题不超过 2 行，正文不超过 6 行要点；超出就拆页，不要缩字号硬塞。
6. **演示友好**：支持全屏与键盘翻页；缩放控件默认隐藏，页码角标只在悬停时出现。

## 步骤

1. **定大纲**：每页写 标题 + 一句话论点 + 3~6 条要点，先出大纲给用户确认。
2. **搭骨架**：一个 HTML，`.slide` 卡片纵向排列，用全局 CSS 变量控制字号与间距。
3. **填内容**：文字页用列表，数据页嵌图表，图片页用内联 base64。
4. **加控件**：全局开关（卡片间距 / 是否显示 caption）、隐藏式缩放、全屏快捷键、悬停才显示的页码角标。
5. **排版自检**：逐页检查溢出——标题换行数、要点行数、图片高度；卡片固定高度保证视觉一致。
6. **交付**：给出打开方式与演示快捷键说明，提醒用户可直接改 HTML 文字。

## 输出形态

```
slides.html（单文件）
├─ 顶部工具条：卡片间距 / caption 开关（演示时可隐藏）
├─ .slide 卡片 ×N
│   ├─ 标题（≤2 行）
│   ├─ 正文（要点 ≤6 行 / 图 / 表）
│   └─ caption（卡片下方，可开关）
└─ 键盘：←/→ 或 ↑/↓ 翻页，F 全屏
```

## 反面例子（不要这样）

- 一页塞 15 条要点，字号缩到 12px。
- 图片走外链，离线演示时全是破图。
- 卡片宽度铺满 4K 屏，一行文字拉得老长。
- 页码角标常驻显示，演示时很出戏。
