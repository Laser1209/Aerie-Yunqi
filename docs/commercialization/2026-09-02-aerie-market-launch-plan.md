# Aerie 商业化与投放测试方案

## 产品定位

Aerie 是一款 **本地优先、可替换人格、能执行实际任务的 AI 陪伴桌面应用**。它把聊天、长期记忆、情绪状态、桌面工作区、主动提醒和可选语音/Live2D 放在同一个本地运行边界内。默认产品角色不再绑定“伊塔”或“云栖”：商业版本使用中性模板 **Aerie Companion**，用户可以选择“专注助手、学习搭档、生活管家、创作伙伴”等合规角色；“伊塔”只作为用户自己的私有 persona 数据，不进入发行包默认内容、宣传素材、种子记忆或默认提示词。

## 首发版本（A12）

当前投放测试构建为 `0.3.2-beta.0903-A12`。Windows 安装器和 portable 位于 `D:\aerie-dist-v046`；GitHub Release 上传完成前，官网的下载链接不可视为已上线。

首发只承诺已能稳定验收的能力：Windows 桌面端本地聊天、可选模型接入、会话历史、可编辑人格、工作区工具、主动提醒、离线降级回复和隐私控制。语音、RVC、Live2D 作为可选扩展，不把缺失模型资产宣传成默认能力。

### Companion Studio 连接状态

已加入独立的本地 HTTP 适配层：设置 `AERIE_COMPANION_STUDIO_URL=http://127.0.0.1:8899` 后，Aerie 可通过 `/api/integrations/companion-studio` 查询 Studio 健康状态，并代理 `talk`、`speak`、`asr`。未配置或 Studio 不可用时返回结构化降级状态，不影响 Aerie 主聊天。

### 首发商业边界

已提供本地 entitlement 状态接口：免费层每月 100 次云调用/100,000 tokens，试用层默认 14 天（500 次/500,000 tokens），Pro 状态预留给后续已验证支付 webhook。它只做本地计量，不伪造支付成功，也不限制本地聊天；真实支付接入前不得把“试用”宣传成已订阅。

### 直接投放前必须改动

1. 已将运行时默认人格切换为 `aerie_default` 中性合规模板；默认名称和系统提示词为可配置的 `Aerie Companion`。已有 profile 的 `yita_default` 记录仍保留并可显式切换。
2. 保留 persona 导入/导出和用户本地私有角色目录；禁止把用户自定义 persona 写入产品默认资源或遥测。
3. A05 品牌版 NSIS 安装器已在 `C:\aerie-dist-v045` 生成，资源中写入 commit、版本、runtime SHA-256 和构建时间 manifest，并通过 `/api/health` 暴露非敏感摘要；解包 Electron 已实际拉起后端。Portable 单文件在当前机器上自解压时间过长且受构建盘空间限制，首发测试建议使用 NSIS，Portable 需另做性能/杀毒兼容优化；干净 Windows profile 安装/升级仍需单独验收。
4. Electron 单测已达到 `156 passed / 0 failed`；仍需完成 Windows 干净 profile 冒烟：安装、首次启动、无模型降级、配置保存、发送消息、退出重启。
5. 增加最小产品遥测（仅同意后）：`app_installed`、`onboarding_completed`、`first_message_completed`、`persona_created`、`subscription_started`。默认不采集聊天正文、原始音频、屏幕内容或 persona 私密字段。
6. 明确付费成功边界后再接 OpenAI Ads Pixel/CAPI；Pixel 只放浏览器营销页，CAPI 只在服务端发送 `subscription_created` 或 `trial_started`，使用同一 `event_id` 去重，失败不得阻塞注册/支付。

## 三阶段投放测试

### 阶段 A：封闭可用性测试

招募 10-20 名 Windows 用户，提供免费本地版。成功标准：安装成功率 >= 90%，首次启动成功率 >= 95%，首次消息完成率 >= 80%，崩溃率 < 2%，用户能在 5 分钟内完成模型配置或使用本地降级模式。记录安装日志和匿名错误代码，不收集聊天内容。

### 阶段 B：价值验证

提供免费层（本地聊天、基础记忆、一个工作区）和 Pro 试用层（多 persona、主动提醒、语音/Live2D 连接器、高级工作区自动化）。测试两个定价页版本，但保持相同产品功能。核心指标：激活率、7 日留存、主动功能使用率、试用转付费率、退款率和每个激活用户的支持成本。不要在未验证的外部 provider 成本模型上承诺无限云端调用。

### 阶段 C：小额广告测试

仅投放已通过隐私审查的营销页，先用小预算比较三组信息：隐私控制、可执行工作流、可替换人格。转化事件只取 `registration_completed`、`trial_started`、`subscription_created`；不以“点击下载”作为唯一成功指标。广告文案不得暗示医疗、恋爱承诺、实时监控或完全离线的外部语音能力。

## 卖点与宣传文案

### 核心卖点

- **你的数据留在你的电脑上**：本地优先，云端模型由用户自行选择；没有默认上传聊天正文。
- **不只会聊天，还能做事**：工作区、文件整理、日程和桌面工具通过权限闸门执行，操作可追踪、可撤回。
- **人格可替换而不是被产品绑架**：从中性模板开始，用户可以创建、导入和隔离多个角色。
- **从文字到声音和形象的扩展边界清楚**：TTS、RVC、Live2D 是可插拔连接器，缺少服务时核心聊天仍能降级运行。

### 短广告文案

> **Aerie：住在你电脑里的本地 AI 伙伴。**
> 聊天、记忆和工作流都由你掌控；选择自己的模型、人格和语音，不必把私人对话交给一个黑箱。

### 商店描述

> Aerie 是本地优先的 Windows AI 伙伴：它记得你的工作上下文，也能在授权范围内整理文件、提醒日程、连接语音和数字人形象。默认从中性、合规的 Companion 模板开始，所有 persona 都可替换、隔离和删除。没有可用模型时仍提供明确的本地降级反馈。

## 商业风险

- Windows 权限、杀毒软件和 Python runtime 打包仍是首发稳定性风险。
- 用户自备模型、Cubism SDK、RVC 权重和第三方 API 的许可证必须分别审查。
- “AI 陪伴”文案不得制造依赖、排他关系、医疗效果或未成年人不当互动暗示。
- 服务端密钥、支付信息和广告归因数据不能进入 Renderer、日志、安装包或 persona 导出文件。

## 投放结论

当前代码已经足够进行 **内部/封闭可用性测试**，还不适合公开大规模投放。完成默认人格脱敏、Electron 可复现构建、剩余测试失败和隐私/支付边界后，可以开始小预算阶段 C 测试。

构建空间注意：A05 安装器及解包目录现存放于 `D:\aerie-dist-v045`，避免占用空间紧张的 C/E 盘。
