# 证据收集规范

本页用于说明证据目录的采集、命名、登记与关联规则。所有证据都应优先回链到 [[07_证据目录]]，再链接到具体的 [[06_验证索引|验证项]] 或 [[05_审计报告|审计发现]]。

## 命名建议

| 类型 | 命名格式 | 示例 |
| --- | --- | --- |
| 命令输出 | `YYYYMMDD-HHMM-命令目标.txt` | `20260727-1530-vault-file-list.txt` |
| 截图 | `YYYYMMDD-HHMM-场景.png` | `20260727-1532-obsidian-graph.png` |
| 日志 | `YYYYMMDD-HHMM-模块.log` | `20260727-1535-startup.log` |
| 报告 | `YYYYMMDD-主题.md` | `20260727-audit-summary.md` |

## 登记规则

- 每份证据必须登记 ID、类型、路径、采集时间、摘要与关联对象。
- 命令输出应保留命令、环境和关键结果摘要。
- 截图应说明页面、操作路径和预期观察点。
- 日志应截取必要范围，避免记录密钥、令牌与个人敏感信息。
- 外部链接应注明访问时间与来源可信度。

## 证据质量

| 维度 | 要求 |
| --- | --- |
| 可复现 | 能说明采集步骤或命令 |
| 可定位 | 能指向模块、验证项或审计发现 |
| 可审查 | 摘要足够支撑结论 |
| 安全 | 不包含明文密钥、令牌或敏感隐私 |
