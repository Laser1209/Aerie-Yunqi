## 1. 设计原则

### 1.1 核心理念

Aerie 是一个有温度的 AI 桌面伴侣，不是一个冰冷的工具。界面语言需传达以下感受：

- **陪伴感（Companionship）**：柔和的圆角、温暖的珊瑚粉点缀、呼吸光晕，让用户感受到 AI 的"在场"。
- **通透感（Clarity）**：玻璃态材质保证信息层次清晰，不堆砌装饰，内容始终是焦点。
- **呼吸感（Breathing Space）**：充足的留白、柔和的阴影、弹性的动效，让界面有生命力。
- **一致感（Consistency）**：所有界面使用同一套 tokens，组件行为可预期。

### 1.2 视觉方向

| 维度 | 选择 | 说明 |
|---|---|---|
| 整体风格 | 温暖玻璃态（Warm Glassmorphism） | 不是冷白苹果风，加入珊瑚粉陪伴色和呼吸光晕 |
| 圆角倾向 | 大圆角 / 胶囊 | 按钮、头像、徽章、灵动岛全部使用胶囊圆角 |
| 材质层次 | 三层玻璃 | 背景（模糊壁纸）→ 卡片（blur 20px）→ 浮层（blur 30px）|
| 阴影风格 | 柔和多层 | 避免生硬黑阴影，使用多层 rgba 叠加营造悬浮感 |
| 色彩情绪 | 冷静蓝 + 温暖粉 | 主色天空蓝（可靠），辅色珊瑚粉（情感/陪伴）|

## 2. 色彩系统

### 2.1 品牌主色（Brand）

主色选用温暖的天空蓝 `#4A90D9`，传达可靠、冷静、智能的感受，相比苹果原生蓝更柔和。

| `--brand-200` | `#B4CFf3` | 边框、分割线 |

### 2.8 色彩使用禁忌

- ❌ 不要将珊瑚粉 `--coral-500` 用于普通按钮、链接等非情感功能
- ❌ 不要在同一区域使用超过 3 种彩色（品牌蓝 + 1 功能色 + 1 情感色）
- ❌ 不要使用纯黑 `#000` 作为文字色（使用 `--text-900 #1A1D23`）
- ❌ 不要在玻璃态卡片上叠加纯白背景，会破坏通透感
- ✅ 功能色（红/绿/黄/蓝）必须搭配对应浅色底色使用，不能大面积纯色填充
- ✅ 渐变只能用于：情感按钮、悬浮球、灵动岛状态点、渐变文字，禁止大面积渐变背景

## 3. 字体体系

### 3.1 字体族

| Token | 字体栈 | 用途 |
|---|---|---|
| `--font-sans` | `-apple-system, "PingFang SC", "Microsoft YaHei UI", "Segoe UI", "SF Pro Display", "DM Sans", system-ui, sans-serif` | 正文、UI 文字 |
| `--font-display` | `"PingFang SC", "DM Sans", system-ui, sans-serif` | 大标题、Display 文字 |
| `--font-mono` | `"JetBrains Mono", "SF Mono", "Cascadia Code", "Consolas", monospace` | 代码、时间戳、数据 |

**多语言适配**：
- 中文优先使用苹方（PingFang SC）/ 微软雅黑 UI，确保中英文混排时基线对齐
- 英文回退 SF Pro Display / DM Sans，数字使用 tabular-nums 保持等宽
- 日文/韩文系统自动回退到系统默认字体

### 3.2 字号阶梯

基准字号 **14px**，使用 **1.25**  Major Third 比例递增。

| 级别 | Token | 字号 | 字重 | 行高 | 字间距 | 用途 |
|---|---|---|---|---|---|---|
| Display | `--text-4xl` | 36px | 700 | 1.2 | -0.01em | 欢迎页大标题、空状态 |
| H1 | `--text-3xl` | 28px | 700 | 1.2 | -0.01em | 页面主标题 |
| H2 | `--text-2xl` | 22px | 600 | 1.25 | -0.005em | 卡片标题、区域标题 |
| H3 | `--text-xl` | 18px | 600 | 1.35 | 0 | 弹窗标题、小节标题 |
| H4 | `--text-lg` | 16px | 500 | 1.4 | 0 | 次级标题、列表标题 |
| Body | `--text-base` | 14px | 400 | 1.65 | 0 | 正文、聊天消息 |
| Caption | `--text-sm` | 12px | 400 | 1.5 | 0 | 辅助文字、时间戳 |
| Overline | `--text-xs` | 11px | 600 | 1.35 | 0.06em | 标签、徽章、uppercase 文字 |

### 3.3 字重使用规则

| 字重 | 值 | 使用场景 |
|---|---|---|
| Light 300 | `--font-light` | 大标题中的细体装饰、英文副标题 |
| Regular 400 | `--font-normal` | 正文、说明文字、聊天消息 |
| Medium 500 | `--font-medium` | 按钮文字、输入框文字、列表项标题 |
| Semibold 600 | `--font-semibold` | 卡片标题、弹窗标题、导航选中项 |
| Bold 700 | `--font-bold` | 页面主标题、数字强调、品牌文字 |

### 3.4 排版禁忌

- ❌ 正文不要小于 12px（聊天消息至少 14px）
- ❌ 不要在大段文字上使用 uppercase（仅 Overline 标签可用）
- ❌ 一行文字不要超过 70 个字符（聊天气泡最宽 75%）
- ✅ 中文段落行高至少 1.65，英文段落至少 1.5
- ✅ 数字（时间、金额、进度）统一使用 `font-variant-numeric: tabular-nums`

## 4. 间距与布局

### 4.1 间距基数

以 **4px** 为基础单位（1 unit = 4px），所有间距必须是 4 的倍数。

| Token | 值 | 典型用途 |
|---|---|---|
| `--space-1` | 4px | 图标与文字间距、紧凑内边距 |
| `--space-2` | 8px | 标签内边距、小间距 |
| `--space-3` | 12px | 卡片内元素间距、按钮内边距 |
| `--space-4` | 16px | 卡片内边距、表单项间距 |
| `--space-5` | 20px | 区域内边距 |
| `--space-6` | 24px | 卡片大内边距、区域间距 |
| `--space-8` | 32px | 区块间距、段落间距 |
| `--space-10` | 40px | 大区块间距 |
| `--space-12` | 48px | 页面边距（大屏）|
| `--space-16` | 64px | 分区大间距 |
| `--space-20` | 80px | Hero 区域间距 |

### 4.2 栅格系统

桌面端采用 **12 列栅格**：

| 断点 | 宽度 | 列数 | 栏间距（Gutter）| 页边距 |
|---|---|---|---|---|
| 小屏（紧凑窗口）| < 960px | 8 列 | 16px | 20px |
| 标准 | 960–1280px | 12 列 | 20px | 24px |
| 大屏 | 1280–1440px | 12 列 | 24px | 32px |
| 超大屏 | > 1440px | 12 列 | 24px | 48px（内容区最大宽度 1400px 居中）|

### 4.3 组件内边距规则

| 组件类型 | 水平内边距 | 垂直内边距 |
|---|---|---|
| 小型按钮（sm）| 12px | 0（高度 28px）|
| 标准按钮（md）| 16px | 0（高度 36px）|
| 大型按钮（lg）| 24px | 0（高度 44px）|
| 输入框（md）| 16px | 0（高度 36px）|
| 卡片 | 20px | 20px |
| 弹窗 body | 24px | 20px |
| 列表项 | 16px | 12px |
| 聊天气泡 | 16px | 10px |
| 导航项 | 12px | 0（高度 40px）|

### 4.4 布局禁忌

- ❌ 不要使用奇数像素的间距（会导致 sub-pixel 模糊）
- ❌ 不要让内容贴边，任何内容距离容器边缘至少 16px
- ❌ 不要在同一层级混用不同的间距节奏（保持 8px 的倍数关系）
- ✅ 相关元素靠近（间距小），不相关元素远离（间距大）
- ✅ 移动端/小窗口下自动减少列数和间距，但保持 4px 基数

## 5. 圆角与阴影

### 5.1 圆角体系

Aerie 使用**大圆角**营造柔和、友好的感觉。

| Token | 值 | 用途 |
|---|---|---|
| `--radius-xs` | 4px | 小标签、进度条 |
| `--radius-sm` | 8px | 小型输入框、徽章 |
| `--radius-md` | 12px | 输入框、复选框 |
| `--radius-lg` | 16px | 卡片默认、图片容器 |
| `--radius-xl` | 20px | 大卡片、下拉面板 |
| `--radius-2xl` | 24px | 弹窗、抽屉 |
| `--radius-full` | 9999px | 按钮、头像、徽章、灵动岛、悬浮球（胶囊）|

**圆角规则**：
- 按钮、头像、徽章、开关、悬浮球、灵动岛必须使用全圆角（胶囊）
- 卡片使用 16px，弹窗使用 24px
- 容器内的子元素圆角应比容器小 4px（如卡片内图片圆角 = 16 - 4 = 12px）
- 禁止使用直角（0px），最小组件圆角 4px

### 5.2 阴影体系

采用**多层柔和阴影**营造层次感，避免生硬的黑色阴影。

| Token | 值 | 用途 |
|---|---|---|
| `--shadow-xs` | `0 1px 2px rgba(0,0,0,0.04)` | 发丝线，输入框默认 |
| `--shadow-sm` | `0 1px 3px rgba(0,0,0,0.06), 0 1px 2px rgba(0,0,0,0.04)` | 卡片默认 |
| `--shadow-md` | `0 4px 8px rgba(0,0,0,0.06), 0 2px 4px rgba(0,0,0,0.04)` | 卡片悬浮 |
| `--shadow-lg` | `0 12px 24px rgba(0,0,0,0.07), 0 4px 8px rgba(0,0,0,0.04)` | 下拉、浮层 |
| `--shadow-xl` | `0 20px 40px rgba(0,0,0,0.08), 0 8px 16px rgba(0,0,0,0.05)` | 气泡、抽屉 |
| `--shadow-2xl` | `0 24px 64px rgba(0,0,0,0.10)` | 模态弹窗 |
| `--shadow-glow` | `0 0 24px rgba(74,144,217,0.25), 0 0 48px rgba(255,138,128,0.15)` | AI 活跃光晕、悬浮球呼吸 |

### 5.3 阴影使用规则

- 同一页面保持光源方向一致（阴影向下偏移，模拟顶部光源）
- 玻璃态卡片使用半透明背景 + 轻阴影，不要使用重阴影
- `--shadow-glow` 仅用于 AI 活跃状态，普通 UI 禁用
- 深色模式下阴影透明度减半（背景已深，不需要重阴影）

## 6. 图标与插画

### 6.1 图标规范

| 维度 | 规范 |
|---|---|
| 图标库 | Lucide Icons（优先，线性风格）|
| 风格 | 线性（Stroke width 1.5–2px），圆角端点（round caps/joins）|
| 视觉重量 | 均衡，不要过粗或过细 |
| 颜色 | 继承 `currentColor`，默认跟随文字色 |

| 尺寸 | Token | 使用场景 |
|---|---|---|
| 14px | `--size-icon-sm` | 按钮内图标、小标签 |
| 18px | `--size-icon-md` | 导航项、输入框图标、列表项 |
| 24px | `--size-icon-lg` | 工具栏、空状态图标 |
| 32px | `--size-icon-xl` | 功能入口、人格卡片 |

**图标与文字搭配规则**：
- 图标 + 横向文字：间距 8px，图标与文字视觉居中（考虑文字 x-height）
- 图标 + 纵向文字（Tab 栏）：图标 24px，文字 11px，间距 4px
- 按钮内图标比按钮文字小 2px（如 14px 文字配 12px 图标）
- 纯图标按钮最小点击区域 36×36px，图标居中 18px

### 6.2 插画规范

| 维度 | 规范 |
|---|---|
| 风格 | 扁平渐变 + 微质感，避免过度写实 |
| 色彩 | 使用品牌色 + 情感色 + 2 个柔和辅助色，不超过 5 色 |
| 线条 | 圆角、柔和、不使用尖锐折线 |
| 主题 | 陪伴、自然、光感（云朵、星辰、光晕、柔和渐变）|
| 使用场景 | 空状态、欢迎页、人格形象、情绪可视化 |

**插画使用原则**：
- 插画不喧宾夺主，最大宽度不超过内容区的 50%
- 空状态插画尺寸 ≤ 200×200px，配合一句温暖文案
- 人格形象插画使用圆角轮廓 + 柔和渐变 + 轻微光晕
- 禁止使用卡通过度可爱（kawaii）或企业感过强的插画风格

### 6.3 AI 形象与人格视觉

- AI 头像默认使用渐变圆形（品牌蓝 → 珊瑚粉）+ 中央光点，可替换为人格设定图片
- 人格卡片中的形象使用圆形裁切，边框 2px 带情感色 glow
- 情绪状态用不同颜色的呼吸光点表示（见情感色表）

## 7. 动效规范

### 7.1 动效时长

| Token | 时长 | 用途 |
|---|---|---|
| `--duration-instant` | 100ms | 按钮按下、开关切换 |
| `--duration-fast` | 150ms | hover、focus 反馈 |
| `--duration-normal` | 240ms | 标准过渡（展开/收起、出现/消失）|
| `--duration-slow` | 360ms | 页面切换、抽屉滑出 |
| `--duration-slower` | 500ms | 大弹窗入场、欢迎动画 |

### 7.2 缓动曲线

| Token | 贝塞尔值 | 用途 | 感受 |
|---|---|---|---|
| `--ease-out` | `cubic-bezier(0.22, 1, 0.36, 1)` | 元素入场（快速启动，柔和收尾）| 自然、流畅 |
| `--ease-in-out` | `cubic-bezier(0.65, 0, 0.35, 1)` | 状态切换（对称）| 稳定 |
| `--ease-spring` | `cubic-bezier(0.34, 1.56, 0.64, 1)` | 情感化动效、灵动岛展开、悬浮球 | 弹性、有生命力 |

### 7.3 动效类型与使用场景

| 动效类型 | 时长 | 缓动 | 场景 |
|---|---|---|---|
| Fade 淡入淡出 | 150–240ms | ease-out | 文字、图标颜色变化 |
| Scale 缩放 | 240ms | ease-spring | 按钮点击（0.96→1）、弹窗入场（0.95→1）|
| Slide 滑动 | 240–360ms | ease-out | 抽屉、下拉菜单、侧边栏 |
| Breath 呼吸 | 4000ms 循环 | ease-in-out | AI 在线状态点、悬浮球 |
| Glow 光晕 | 2000ms 循环 | ease-in-out | AI 思考中、录音状态 |
| Typing 打字 | 600ms 循环 | — | AI 输入中三点跳动 |

### 7.4 动效禁忌

- ❌ 不要给所有元素加动效，动效仅用于反馈和引导注意力
- ❌ 不要让动效时长超过 500ms（循环呼吸/光晕除外）
- ❌ 不要使用弹跳、旋转、闪烁等夸张动效（AI 思考/庆祝场景除外）
- ❌ 不要在文字颜色变化上使用超过 150ms 的过渡
- ✅ 尊重系统 `prefers-reduced-motion` 设置，减弱或关闭非必要动效
- ✅ 列表项使用 stagger 动画（每项延迟 30ms），但不要超过 10 项

## 8. 组件规范

> 所有组件样式类以 `aerie-` 前缀命名（如 `.aerie-btn`、`.aerie-card`），避免与宿主样式冲突。  
> 完整 CSS 实现见 `components/components.css`，设计令牌见 `tokens/colors_and_type.css`。

### 8.1 Button 按钮

**变体**：

| 变体 | 背景 | 文字 | 阴影 | 使用场景 |
|---|---|---|---|---|
| Primary | `--color-primary` | 白 | shadow-sm | 主要行动（发送、确认、保存）|
| Secondary | 玻璃白 `--glass-bg` | `--color-text` | shadow-sm | 次要行动（取消、返回）|
| Ghost | 透明 | `--color-text` | 无 | 工具栏、卡片内操作 |
| Danger | `--color-error` | 白 | shadow-sm | 删除、不可逆操作 |
| Emotion | 渐变 `--emotion-pleasure→coral-400` | 白 | shadow-glow | AI 互动（开始对话、人格激活）|
| Text | 透明 | `--color-primary` | 无 | 链接式操作（了解更多、查看全部）|

**尺寸**：

| 尺寸 | 高度 | 水平内边距 | 字号 | 图标 |
|---|---|---|---|---|
| sm | 28px | 12px | 12px | 12px |
| md | 36px | 16px | 14px | 14px |
| lg | 44px | 24px | 16px | 18px |

**状态**：
- **Default**：默认样式
- **Hover**：Primary/Danger/Emotion 亮度降低 4%；Secondary/Ghost 背景变为 `--color-surface-hover`；Text 文字变为主色
- **Active/Pressed**：缩放 0.98，亮度再降 4%
- **Focused**：2px 主色外发光，offset 2px
- **Disabled**：透明度 0.4，`cursor: not-allowed`，移除 hover 效果
- **Loading**：透明度 0.7，显示旋转 spinner，禁止点击

**使用禁忌**：
- ❌ 一行中 Primary 按钮不要超过 1 个
- ❌ 不要在弹窗底部放置超过 2 个按钮（主操作右，次操作左）
- ❌ Danger 按钮不要使用 sm 尺寸（危险操作需要足够点击面积）
- ✅ 按钮文字使用动词（发送、确认、保存），不要使用"好的""确定"等模糊词

### 8.2 Input 输入框

**变体**：默认、Search（带搜索图标）、Password（带显示/隐藏切换）、With Prefix/Suffix

**尺寸**：sm（32px）、md（36px）、lg（44px）

**状态**：
- Default：1px `--border-default` 边框，背景 `--bg-50/80`
- Hover：边框变为 `--bg-400`
- Focused：边框变为 `--color-primary`，3px `--brand-100` 外发光
- Error：边框 `--color-error`，3px `rgba(255,69,58,0.12)` 外发光，下方显示错误提示
- Disabled：透明度 0.5，背景 `--bg-200`
- Readonly：背景 `--bg-100`，边框不变，不可编辑

**规则**：
- 占位文字使用 `--text-300` 色，字号与输入文字一致
- 错误提示文字 12px，颜色 `--color-error`，距离输入框 4px
- 输入框前/后图标颜色 `--text-400`，尺寸 16px
- 聊天输入框使用自适应高度（最小 44px，最大 160px）

### 8.3 Card 卡片

**变体**：

| 变体 | 背景 | 阴影 | 边框 | 使用场景 |
|---|---|---|---|---|
| Default | `--glass-bg` + blur(20px) | shadow-sm | glass-border | 通用卡片 |
| Elevated | 同上 | shadow-lg | glass-border-strong | 需要突出的卡片 |
| Interactive | 同上 | shadow-sm + hover:shadow-lg | glass-border + hover:primary/50 | 可点击卡片 |
| Glass Strong | `--glass-bg-strong` + blur(30px) | shadow-md | glass-border-strong | 重要面板 |
| Flat | `--color-surface` | 无 | `--border-default` | 列表内嵌卡片 |
| Emotion | glass-bg + 情感色 glow | shadow-md + glow | `--emotion-pleasure/30` | 情绪/人格卡片 |

**结构**：
- `.aerie-card-header`：20px 内边距，底部可能有 divider
- `.aerie-card-body`：20px 内边距
- `.aerie-card-footer`：20px 内边距，顶部可能有 divider，右对齐操作按钮

**Hover 行为**（Interactive）：

### 8.4 Modal 模态弹窗

**结构**：遮罩层 + 弹窗面板 + 关闭按钮

**规则**：

### 8.5 Drawer 抽屉

## 12. 可访问性

### 12.1 对比度要求

- **正文文字**（≥ 14px 常规 / ≥ 12px 粗体）：对比度 ≥ 4.5:1（WCAG AA）
- **大标题**（≥ 18px 常规 / ≥ 14px 粗体）：对比度 ≥ 3:1（WCAG AA）
- **图标/图形**：与背景对比度 ≥ 3:1
- **禁用态文字**：不要求对比度，但必须视觉明显（opacity 0.4）

### 12.2 键盘导航

- 所有可交互元素必须可通过 Tab 聚焦
- 聚焦态必须有清晰的视觉指示（2px 主色 outline，offset 2px）
- Tab 顺序符合视觉流：左→右，上→下
- 常用快捷键：Enter 确认、Esc 关闭弹窗/抽屉、Ctrl+Enter 发送消息

### 12.3 其他无障碍要求

- 所有图标按钮必须有 `aria-label`
- 表单控件必须有关联的 `<label>`
- 动效尊重 `prefers-reduced-motion: reduce`
- 最小点击区域 36×36px（图标按钮、链接、复选框）
- 颜色不作为唯一信息传递方式（错误态同时使用图标+文字+红色）
- 支持系统字体缩放（最大 150% 不破坏布局）


在代码中使用 token：
```css
.my-button {
  background: var(--color-primary);
  color: var(--color-primary-fg);
  border-radius: var(--radius-full);
  padding: 0 var(--space-4);
  height: var(--size-btn-md);
  font-size: var(--text-base);
  transition: all var(--duration-normal) var(--ease-out);
}
```

### 13.3 设计协作规则

- 设计师在 Figma 中使用同名 token，保持与开发一致
- 新增 token 必须经过设计系统审查，先加入 token 文件再使用
- 组件变体扩展必须先在 `components/index.json` 中注册
- 颜色、字号、间距、圆角、阴影必须从 token 选取，禁止硬编码
- 新增组件必须在本文档中补充规范后才能使用
