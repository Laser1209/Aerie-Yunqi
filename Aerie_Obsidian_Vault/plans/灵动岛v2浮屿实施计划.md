# 灵动岛 v2「浮屿」实施计划

> [!abstract] 计划依据
> 本计划由 [[灵动岛 v2 行业最佳实践调研报告]] 支撑，设计稿为 `.design_library/dynamic-island-v2-preview.html`（第三轮，已浏览器实测通过）。
> 核心结论：**保持 Electron 单窗 + 性能纪律**，专注情绪在场感与前后端数据一体；不引入 Tauri/Rust 重构。

## 设计目标（浮屿 Floating Isle）

1. 液态玻璃 + 情绪光晕（珊瑚粉=想你 / 天空蓝=平静 / 琥珀=低落）。
2. 展开后胶囊拉宽至与面板同宽（窄屏 340 / 宽屏 720），无缝成为面板头部。
3. hover 拉长 200→320；点击外部自动回弹；媒体查询自适应。
4. 无外层阴影（防 Electron 透明窗裁剪割裂）。
5. 头像同步设置页 AI 头像；胶囊文案走后端人情味生成。

## 任务分解

- [x] 运行 `electron/tests/window-lifecycle.test.js` + `system-status.test.js`，记录 pass/fail 数 → **20/20 全绿**
- [x] 记录灵动岛默认配置三源（main.js / dynamic-island.js / settings.js）现状：
  - `main.js` `_islandConfig`：capsule=`["companion","status","notifications"]`、expanded=`["quickActions","notifList"]`

## 风险与护栏

| 风险 | 护栏 |
|---|---|
| Electron 透明窗阴影裁剪割裂 | 设计上取消外层阴影，仅 inset 高光 + 描边 |
| 设置面板配置失效（历史 bug） | 重构 `onConfigChange`/`loadConfig` 校验：白名单 + 至少 1 项，允许取消勾选 |
| 启动拖慢 | 灵动岛 100% Electron 侧、渲染零框架依赖、媒体轮询 idle 15s |
| 头像文件缺失 | img onerror 回退 `assets/logo.png` |

- 2026-08-13（修复）：窗口四周 10px 呼吸边距（main.js `ISLAND_EDGE` + renderer `DI_EDGE`/`setWin` + CSS `.di-inner` padding），防 Electron 透明窗裁切毛玻璃。CDP 实测：初始 220×64 胶囊留白 L10/R10/T10、hover 340 无裁切、open 360 胶囊 340 留白 10、wide 740 胶囊 720 留白 10。Electron 窗口边框差异 2px（222 vs 220）不影响留白。
- 2026-08-13（修复）：鼠标晃动闪烁——根因是 hover 拉长的 `mouseenter/mouseleave` 反复触发 `setBounds`，窗口 220/340 反复跳变 + 收缩定时器未取消互相竞争。修复：enter 120ms 防抖 + leave 400ms 可取消收缩定时器（`shrinkTimer`）+ `resizeCanvas` rAF 节流。CDP 实测：快速晃动 12 次中窗口宽度仅跳变 1 次即稳定（修复前每次进出都跳变）。
- 2026-08-13（重构-固定最大+动态穿透）：窗口固定最大尺寸（main.js `width=740`、`height=704`），hover/展开/宽屏的宽度动画全部在窗口内居中完成，窗口不再 resize —— 消除瞬时裁切与闪烁；桌面遮挡由**动态鼠标穿透**解决（renderer 按鼠标位置实时 `setIgnoreMouseEvents`：鼠标在交互区则接收、离开则穿透；**按住 ALT 强制穿透**）。主进程文件日志实测穿透链路：胶囊外 `true`→胶囊上 `false`→移出 `true`→ALT 按下 `true`→ALT 松开 `false`。最终回归：窗口 742×704（含 2px Electron 边框）、hover 320/展开 340/宽屏 720 全无裁切、简报真实数据渲染、无 JS 错误。
