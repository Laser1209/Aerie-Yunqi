# Aerie 定价、上架与收费入门手册

> 当前基线：`0.3.2-beta.0903-A08`。本文把“软件使用费”和“第三方 API 费”拆开，适用于第一次做产品、上架和收费的负责人。

## 1. 应该收什么钱

推荐模型是：**免费本地核心 + Pro 软件订阅 + API 按实际成本单独结算**。

| 方案 | 测试价格 | 用户买到的内容 | 不包含 |
|---|---:|---|---|
| Free | 0 元/月 | 本地聊天、基础记忆、单 persona、单工作区、离线降级 | 平台补贴的云端无限调用 |
| Pro 封闭测试 | 19 元/月与 29 元/月 A/B | 多 persona、更多工作区、主动提醒、高级记忆视图、连接器管理、优先支持 | 无限 LLM/ASR/TTS/RVC 调用 |
| Pro 年付 | 月价的 8-10 倍 | 与 Pro 月付相同 | 未产生真实支付前不要开放 |
| 团队版 | 99 元/月起，暂不公开 | 共享模板、管理员审计、部署支持 | 账号、权限、发票能力完成前不销售 |

软件订阅费支付的是软件功能、更新和支持；不能把订阅费模糊写成“AI 额度”。

## 2. API 费用怎么处理

首轮优先采用 **BYOK（用户自带 API Key）**：Aerie 不代收 LLM、ASR、TTS、RVC 或生图费用，设置页明确标注“费用由对应供应商直接收取”。这样不会因供应商价格变化或并发失控而亏损。

未来若平台代付，必须单独建立 API 钱包：显示供应商、模型、输入/输出 token 或音频时长、单价、余额和硬上限。余额不足时停止调用，不允许静默透支。

软件订阅和 API 钱包必须是两个状态：取消订阅不代表退还已经产生的第三方调用费；API 余额也不能解锁 Pro 功能。

## 3. 第一次收费前必须具备的文件和系统

### 法律和运营文件

- 商业 EULA/终端用户许可协议；
- 隐私政策、数据删除和导出说明；
- 退款、取消、自动续费和客服政策；
- 第三方模型、语音、Live2D/RVC 资产的许可清单；
- 发票/收据和税务主体信息。

当前仓库 LICENSE 仍是非商业学习、研究和内部评估边界。因此在权利人确认商业 EULA 前，只能做非商业技术评估或书面授权的封闭测试，不应直接公开收取软件费。

### 技术最小闭环

```text
用户选方案 -> 服务端创建订单 -> 支付页
-> 支付供应商 webhook 验签 -> 幂等更新订单/订阅
-> 客户端拉取 entitlement -> 解锁 Pro
```

必须覆盖支付成功、重复 webhook、支付失败、退款、取消续费、网络中断和重新启动。客户端不能以“点击了购买按钮”判断成功，也不能把本地 entitlement 文件当成真实支付凭证。

## 4. 上架顺序

1. **GitHub Release**：先发布 Windows NSIS 安装器，附 SHA-256、已知限制和支持邮箱；portable 作为备选。
2. **自有官网**：只链接已存在的 Release 资产，展示版本、隐私政策、许可、退款入口和状态说明。
3. **小额投放**：先测注册、首次消息和试用，不以下载量作为唯一目标。
4. **Microsoft Store**：待签名、升级、卸载、隐私声明、崩溃处理和客服流程稳定后申请。

不要同时铺开多个商店，否则支付分成、版本回滚、客服和退款责任会被放大。

## 5. 非开发者执行清单

### 现在就能做

- 用 `D:\aerie-dist-v048` 做 10-20 人封闭测试；
- 把 19 元和 29 元写成两个价格页变体；
- 收集安装成功、首条消息、任务完成、留存和支持工时；
- 让用户明确选择自己的模型/API Key；
- 使用中性 `Aerie Companion` 文案，不把私人 persona 放进默认包。

### 暂时不能做

- 没有真实支付供应商和 webhook 时，不显示“已订阅”；
- 没有真实 Pixel ID 和同意机制时，不开启广告转化；
- 不承诺无限 API、完全离线的外部语音或医疗/心理效果；
- 不把聊天正文、音频、屏幕和私有 persona 上传到广告或分析系统。

## 6. 费用计算示例

假设 Pro 为 29 元/月，用户自带 Key：Aerie 的主要成本是支付手续费、更新、客服和存储，毛利更可控。若平台代付 API，应先估算每位用户的月均调用成本 `C`，再设硬上限；售价至少覆盖 `C + 支付手续费 + 客服成本 + 税费 + 风险准备金`，而不是按“所有用户都会轻度使用”估算。

建议先卖软件能力，再按量卖云调用。这样用户知道自己为哪一部分付费，产品也不会因一次高消耗请求承担无限成本。

## 7. 对外一句话

> Aerie Companion 免费提供本地核心；Pro 订阅解锁更完整的记忆、工作流和连接器管理。第三方模型与语音服务按供应商实际用量计费，支持用户自带 API Key，不把 API 成本伪装成无限订阅。
