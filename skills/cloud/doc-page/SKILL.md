# 可打印文档页（doc-page）

当用户要生成**可打印、可编辑的 A4 文档页**时使用：报告、表单、排班表、简历、备忘录、通知。
产出是单文件 HTML，按 A4 排版，需要时导出 PDF 或 DOCX。

## 铁律

1. **按 A4 排版**：页面以 210mm 宽为基准，打印时一页不被截断；分页处不出现半个表格行、半行标题。
2. **打印优先**：正文黑白也能读，不靠颜色区分信息；避免大面积深色底；关键分隔用线而不是背景色。
3. **单文件可编辑**：一个 HTML 文件打开即用，正文是可读的 HTML 结构，用户能直接改字。
4. **中文字体可靠**：用系统字体栈（如 "Microsoft YaHei"、"PingFang SC"、sans-serif），不依赖在线字体。
5. **表单留书写空间**：表单、记录类要留出打印后可手写的行高（≥8mm），或做成可输入的输入框。
6. **导出与所见一致**：PDF / DOCX 导出结果与页面视觉一致，字号、页边距、分页不跑偏。

## 步骤

1. **明确用途与读者**：是打印还是电子传阅、谁来填、需不需要签字栏或盖章位——先问清再排版。
2. **定版式**：选模板骨架（正文报告 / 表单 / 表格排班 / 简历 / 备忘录）。表格类用 `<table>` + 固定列宽，别用浮动布局。
3. **设页面尺寸**：`@page { size: A4; margin: 20mm }`，正文容器宽度与 A4 对齐。
4. **排内容**：标题层级清晰；表格设 `page-break-inside: avoid`，标题设 `page-break-after: avoid`。
5. **加导出**：需要时挂 PDF 导出（走打印样式）与 DOCX 导出（保留标题层级与表格结构）。
6. **打印预览自检**：在浏览器打印预览中逐页翻，确认无内容被切、无空白页、页脚页码正确。
7. **交付说明**：告诉用户怎么改内容、怎么导出、纸张与缩放怎么选（如缩放保持 100%）。

## 输出形态

```
doc.html（单文件，A4）
├─ @page A4 + 打印样式
├─ 标题区：标题 / 编号 / 日期 / 版本
├─ 正文：分节（标题 + 段落 / 表格 / 表单行）
├─ 签字区：经办 / 审核 / 日期（如需要）
└─ 页脚：页码 / 页数
导出：打印为 PDF；DOCX（保留表格与标题层级）
```

## 反面例子（不要这样）

- 表格跨页被切成两截，第二页只剩表头。
- 用颜色承载关键信息，黑白打印后全糊在一起。
- 页面写死 1440px 宽，打印时右侧被裁掉。
- 简历或表单没留签字、手写空间，打印后没法用。
