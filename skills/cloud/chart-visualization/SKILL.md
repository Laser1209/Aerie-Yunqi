# 图表可视化（chart-visualization）

当用户有一组数据要可视化，需要**从图库里挑出最合适的一种图并渲染**时使用。
流程是：先明确要回答什么问题，再据此选型，然后提取参数，最后出图并附上所用数据。

## 铁律

1. **先问要回答什么，再选图**：是看趋势、比大小、看构成、看分布还是看相关？图型由问题决定，不由数据形状决定。
2. **一图一结论**：每张图只服务一个结论，标题写成结论句（如"Q3 华东占比升至 38%"），不要只写"各区域占比"。
3. **轴与单位必须标**：纵轴标单位；不要双轴混用造成假相关；雷达图、饼图不适合比较绝对值。
4. **构成类慎用饼图**：类别超过 5 个、或需要比较相近占比时，改用条形图或堆叠条。
5. **点数太少或太多都要换图**：少于 3 个点用表格；上千个点考虑聚合或改用密度图、箱线图。
6. **不误导**：纵轴一般不从非零起点截断，若截断必须显式标注；颜色不承载额外含义时不用彩虹色。

## 步骤

1. **提取问题与数据**：确认字段、单位、时间范围、缺失值，列出想问的 1~3 个问题。
2. **选型**：按问题映射图型——趋势→折线/面积；比大小→条形；构成→堆叠条或饼（≤5 类）；分布→直方图/箱线；相关→散点；多维对比→雷达/平行坐标；流向→桑基；累计或归因→瀑布。
3. **点名理由**：写一句"选 X 因为要回答 Y"，并说明备选图型以及不选它的原因。
4. **提参数**：写清 X/Y 字段、聚合方式（求和/均值/计数）、排序、单位、颜色语义、是否堆叠。
5. **渲染**：按参数出图，标题写成结论句，标注单位与数据来源。
6. **可读性检查**：标签不重叠、图例不遮数据、刻度合理、配色可辨（含色盲）；必要时旋转标签或改用横向条。
7. **附上数据**：交付图的同时给出所用数据表，方便复核。

## 输出形态

```
## 选型
- 要回答的问题：…
- 选用图型：<图型>，理由：…
- 备选与不选原因：…

## 参数
| 项 | 取值 |
| x | … |
| y | … |
| 聚合 | … |
| 单位 | … |

## 图
（标题 = 结论句；含单位与来源）

## 所用数据（表格）
```

## 反面例子（不要这样）

- 6 个类别硬塞进饼图，谁都看不出谁大。
- 用双 Y 轴让两条线"看起来正好交叉"，制造假相关。
- 纵轴从 90 开始截断却不标注，夸大差异。
- 图做得漂亮，但读者说不出它想表达什么。
