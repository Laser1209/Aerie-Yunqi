新版户型选择：玄关独立 + 面积放大

目标从 84㎡ 小 LOFT 调整为更有设计余量的江景复式：玄关不能被楼梯挡住，楼梯必须自然接入公共动线，外轮廓保留真实户型的退台和凹凸。

A · 96㎡ 紧凑放大

一层约 60㎡、二层约 36㎡。玄关独立，楼梯靠右侧服务核，但工作室和衣帽储物仍偏紧。

B · 推荐 118㎡

一层约 72㎡、二层约 46㎡。玄关完整，楼梯移到中部服务核旁，客餐厅朝江景展开，二层可容纳主卧、工作室、衣帽和主卫。

C · 132㎡ 展示型

一层约 80㎡、二层约 52㎡。空间最舒展，可做景观楼梯和独立衣帽间，但会偏豪宅样板间，成本和工作量更高。

我推荐 B · 118㎡ 的原因
  • 玄关从入户门到客餐厅有完整缓冲，不被楼梯压迫。
  • 楼梯放在中部服务核旁，既节省面积，又自然连接二层桥廊。
  • 不规则外轮廓更接近真实重庆公寓户型：北侧服务核退台、南侧江景面展开。
  • 面积增加后可容纳更多伊塔设定物件：独立工作室、衣帽间、主卫浴缸、书柜墙、用户物件展示位、设备柜和储物间。
  • 仍然不会过度膨胀，后续 JSON 坐标、平面图和效果图重做成本可控。
