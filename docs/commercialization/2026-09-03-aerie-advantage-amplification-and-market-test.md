# Aerie 优势放大与首轮市场测试手册

> 版本基线：`0.3.2-beta.0903-A09`。本文面向没有做过产品开发、上架和投放的负责人，目标是用最小成本验证“用户是否愿意持续使用”，而不是先把所有功能都做完。

## 1. 先卖清楚一个结果

Aerie 不应该被包装成“又一个聊天机器人”，也不应该默认绑定伊塔、云栖或任何私人角色。正式产品使用中性合规的 **Aerie Companion**，用户可以把它改成专注助手、学习搭档、创作伙伴或生活管家。

首轮建议采用 **内容创作者/主播为主、个人生产力用户为辅** 的市场切入：他们既能感知语音、人格和桌面工作流的价值，也能产出可公开演示的使用案例。

推荐定位：

> **Aerie Companion：把 AI 放进你的桌面工作流。对话、记忆和角色由你掌控，需要联网时由你选择模型和连接器。**

## 2. 把优势放大成证据

不要只罗列“记忆、语音、Live2D、提醒”等功能。每一个卖点都必须能在 30 秒内演示，并能说明边界。

| 优势 | 演示方式 | 用户得到的结果 |
|---|---|---|
| 本地优先 | 打开数据目录、联网开关和 Key 归属页 | 知道哪些数据留在电脑上 |
| 从聊天到执行 | 说“整理本周素材”，展示预览、授权、执行日志 | 节省重复操作时间 |
| 人格可替换 | 切换两个合规 persona，历史数据保持隔离 | 不被单一品牌人设绑定 |
| 可替换连接器 | 断开云模型或 Companion Studio，展示结构化降级 | 不会因一个服务故障而整套失效 |
| 可控主动性 | 展示提醒原因、暂停和撤回入口 | 主动功能可理解、可关闭 |

产品页首屏只保留一个动作：下载并完成第一条消息。语音、RVC、Live2D 和高级主动能力放在“可选连接器”区域，不把未配置的模型写成默认能力。

## 3. 与同赛道产品的竞争位置

| 竞品方向 | 它们更强的地方 | Aerie 不应硬拼的地方 | Aerie 应放大的差异 |
|---|---|---|---|
| Character.AI | 角色数量和社区规模 | 角色生态、云端规模 | 本地数据边界、工作流执行 |
| Replika/Nomi/Kindroid | 陪伴连续性和关系叙事 | 情感关系深度、移动端成熟度 | 中性合规默认、人格隔离、桌面生产力 |
| Pi | 低门槛通用对话 | 云端可用性和品牌认知 | 模型可替换、可本地降级 |
| LM Studio/Ollama | 本地模型和开发者控制 | 模型运行工具的深度 | 在本地模型之上增加记忆、权限和执行 |

因此 Aerie 的广告主张应是“**陪伴 + 可执行工作流 + 数据控制**”，而不是“角色最多”“最像真人”或“无限 AI”。

## 4. 三阶段投放方案

### 阶段 A：封闭可用性（10-20 人，1-2 周）

使用 D 盘构建包 `D:\aerie-dist-v048`。让用户完成：安装、首次启动、选择/创建 persona、发送第一条消息、执行一次工作区任务、断开外部服务后重试。

通过标准：安装成功率 >= 90%，首次消息完成率 >= 80%，关键流程崩溃率 < 2%。只收集匿名错误代码和流程指标，不收集聊天正文、原始音频、屏幕内容或私有 persona。

### 阶段 B：价值测试（2-4 周）

保持功能和页面一致，只测试三种主标题：

1. “你的 AI 数据，留在你的电脑上。”
2. “从一句话开始，把工作推进下去。”
3. “模型、人格和连接器，都由你选择。”

观察首条消息、工作区任务完成、7 日留存和试用激活，不要只看下载量。

### 阶段 C：小预算广告（通过许可和隐私闸门后）

官网只部署真实 Pixel ID，并取得必要的用户同意。事件只发送 `registration_completed`、真实 `trial_started` 和真实 `subscription_created`，用同一 `event_id` 去重；没有真实支付边界时不得伪造订阅成功。

先用一个很小的固定预算跑 7 天，按 UTM 比较三个主标题。只有当安装、首次消息和支持成本稳定后，才扩大预算或申请商店上架。

## 5. 可直接使用的文案

### 广告主标题

> **不是把你的数据交给黑箱，而是把 AI 放回你的工作流。**

### 广告正文

> Aerie Companion 是本地优先的 Windows AI 伙伴：它能记住工作上下文，也能在你授权后整理文件、安排提醒并连接语音工具。模型、人格和 API Key 由你选择。免费使用本地核心，Pro 解锁更完整的工作流能力；第三方 API 费用透明分开。

### 下载按钮附近

> Windows `0.3.2-beta.0903-A09` 公开测试版：中性合规默认角色，本地优先，外部服务不可用时明确降级。

### 禁用表达

不要使用“永远陪着你”“替代心理咨询”“完全离线语音”“无限调用”“不会忘记你”等无法验证或容易造成误解的承诺。

## 6. 目前不足与修复优先级

1. 先完成干净 Windows profile 的安装、升级、卸载和重启验收。
2. 把首次运行收敛为“选择角色 -> 选择模型/本地降级 -> 第一条消息”三步。
3. 为每个连接器显示健康状态、费用归属和缺失模型提示。
4. 完成真实支付、退款、发票、客服和商业 EULA 后，再公开收费。
5. 让工作区模板具备预览、明确授权、执行日志和撤销，形成可复制的护城河。

## 7. 首轮成功标准

首轮不是追求注册人数，而是证明陌生用户能独立完成一次有价值的任务，并理解数据和费用边界。建议每周只看：访问、下载、安装成功、首条消息、工作区任务、7 日留存、试用开始、付费成功、退款、支持工时和 API 成本。
