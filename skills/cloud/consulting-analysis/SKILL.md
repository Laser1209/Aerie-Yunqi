# 咨询级报告（consulting-analysis）

当用户要一份**咨询级**的研究/分析报告时使用：行业研究、市场分析、消费者洞察、
品牌分析、财务分析、竞品分析、投资尽调。
分两阶段：先产出**框架 + 数据需求**，数据齐了再产出成稿。

## 铁律

1. **结论先行（金字塔）**：每章开头先给结论句，再用 2~4 条论据支撑，最后放数据。禁止"先铺垫后揭晓"。
2. **每个结论必须有数据或来源**：写不出来源的论断，降级为"假设"并显式标注。
3. **先有框架再找数据**：先定章节骨架与每节要回答的问题，再列数据需求；不要拿到数据反推它能说明什么。
4. **口径统一**：时间范围、单位、口径（含税/不含税、同比/环比、渗透率定义）全篇一致，并在开头写明。
5. **区分事实与判断**：事实标来源，判断标推理链，预测标假设与敏感度。
6. **给可执行结论**：战略建议必须落到"做什么、优先级、前置条件、风险"，不写"应加强""要重视"。

## 步骤

1. **定问题**：把需求方的问题翻译成一个可回答的核心问题（一句话），并列出它隐含的子问题。
2. **出骨架**：给章节目录，每节写"要回答的问题 + 需要的指标/数据 + 预期结论方向"。
3. **列数据需求**：逐条写 指标、口径、来源、时间范围、缺失时的替代方案，交给数据方去取。
4. **收数校验**：数据到手先做合理性检查（量级、加总、与历史/常识对比），冲突的标注并说明取值理由。
5. **写分析**：按"结论 → 论据 → 数据 → 含义"的顺序写，图表只放支撑结论的那一张。
6. **交叉验证**：用第二种方法或第二个来源验证主结论；对不上就回查口径。
7. **出战略结论**：给 2~4 条可执行建议 + 优先级 + 前置条件 + 风险，每条注明依据章节。

## 输出形态

```
## 核心结论（3~5 条，每条一句话）
## 口径与数据来源
## 第 N 章 <标题>
  结论句 → 论据 1/2/3（各带数据）→ [图表] → 对结论的含义
## 战略建议
- 建议 → 依据 → 优先级 → 前置条件 → 风险
## 假设与不确定性
```

## 反面例子（不要这样）

- 堆了 20 张图，却没有一句结论。
- 数据来源缺失，或只写"据行业经验"。
- 同一份报告里"市场规模"前后用了两种口径。
- 建议写成"提升品牌力""加强数字化"，无法执行。
